*TP2*
1. El proyecto se trata de un sistema de clases (abstractas y concretas) con asociaciones variadas (asociación, agregación y composición) (resueltos hasta el ejercicio 3 por ordenes de la cátedra), en él se en encuentran creadas las clases (principalmente EventoUniversitario y Actividad) con sus debidos atributos y métodos solicitados por los requerimientos para su debida representación. En la clase App (el main) se encuentran instanciadas algunos objetos de esas clases con estados variados, junto con varios métodos, pensados así para una comprobación de funcionalidad.
2. En el sistema creado está incluido el manejo de excepciones en cuanto a las inscripciones de los alumnos a las actividades mediante una carpeta con una clase que hereda de Exceptions, también se implementa la serialización de clases ejecutadas y su guardado en archivos
3. El proyecto cuanta también con una interfaz que implementa un método que aplican a aquellas actividades designadas.
4. Dentro de la clase EventoUniversitario se han implementado métodos para filtrar las actividades creadas en el Main por tipo, para ello se han implementado métodos acotados y wildcards.
